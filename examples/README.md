# BrowserX Examples

This directory contains practical code examples demonstrating how to use and extend BrowserX features.

## Examples Included

1. **custom-module-weather/** - Create a custom weather widget module
2. **custom-feed-parser/** - Build custom news feed parser
3. **read-later-feature/** - Complete "Read Later" feature implementation
4. **custom-theme/** - Create and apply custom themes
5. **automation-scripts/** - Browser automation examples

## How to Use Examples

Each example folder contains:
- `README.md` - Detailed explanation
- Source code files
- Installation/usage instructions

## Running Examples

Copy the example code to your BrowserX installation and follow the instructions in each example's README.

## Contributing Examples

Have a cool example? Submit a Pull Request!

1. Create a new folder in `examples/`
2. Add your code and README
3. Test thoroughly
4. Submit PR with description
